# note
- This script calculate the separation distance of AlMg5 extended dislocations under correlated analytical solid solution noise. First, the system is minimized for the number of steps specified by the output frequency.
- To set how many random seeds to test, edit the variable noise_seed_to_test in main.py.
- To set the initial separation distances to test, edit the variable glide_steps_to_test in main.py.
